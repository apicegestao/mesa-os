# Mesa OS Constitution

**Versão:** 1.0  
**Status:** FROZEN

## Produto

Mesa OS é uma plataforma de engenharia de transformação empresarial. A Mesa dos Donos é sua primeira metodologia.

## Core loop

Diagnóstico → Prioridade → Ciclo → Missão → Ferramenta → Implementação → Evidência → Evolução.

## Princípios vinculantes

1. O membro deve sempre compreender onde está, o que precisa fazer e por que isso importa.
2. Complexidade interna não deve ser exposta ao membro.
3. Conteúdo não representa evolução; implementação e transformação representam evolução.
4. Ferramentas são objetos estruturados do sistema, não simples downloads.
5. TutorIA é agente de transformação, não chatbot genérico, e não acessa o banco diretamente.
6. IA não possui autorização implícita para alterar regras críticas.
7. Nenhuma feature fora do backlog e do sprint aprovados entra silenciosamente no produto.
8. Decisões importantes não podem depender da memória de uma conversa.
9. Segurança, privacidade, menor privilégio e rastreabilidade são requisitos, não melhorias opcionais.
10. O V2 Scope Lock é vinculante.

## Regra de conflito

Em caso de conflito, prevalece a autoridade superior definida no Construction Protocol. Decisões `FROZEN` exigem Change Request aprovado.
