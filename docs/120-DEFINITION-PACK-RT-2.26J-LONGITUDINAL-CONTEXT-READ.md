# Definition Pack — RT-2.26J Recuperação Mínima do Contexto TutorIA

**Status:** APPROVED FOR HOMOLOGATION

O TutorIA pode incluir na orientação apenas fatos automáticos de baixo detalhe já autorizados: resumo de diagnóstico concluído e ciclo ativo. A leitura exige Termos atuais aceitos e política organizacional ativa, é limitada a oito itens ativos da própria identidade e gera auditoria por código de fonte.

Ficam excluídos: conversa bruta, memórias digitadas livremente, ferramentas, evidências, dados sensíveis, dados de outra organização e qualquer escrita durante a orientação.
