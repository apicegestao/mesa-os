# Release Pack UXM-3.7 — Mobile and diagnostic reset

**Status:** APPROVED FOR BUILD AND PRODUCTION

## Owner decisions

- mobile is a first-class operating surface: controls, cards, typography and
  navigation must adapt without horizontal page overflow;
- use the supplied Mesa dos Donos artwork as the web and mobile application icon;
- remove the legacy v1 Raio-X execution, which the owner confirmed was test-only;
- retain the v1 definition as a retired audit artifact, but never select it for
  a member. All organizations begin the published v2 instrument.

## Delivery controls

- mobile controls retain at least a 44 px touch target;
- headers on small screens do not use expensive visual blur;
- panels, drawers and diagnostics use the viewport-safe mobile height;
- v1 execution deletion is scoped to its retired revision and was pre-checked
  for absence of responses, priorities, cycles, metrics and memories.
