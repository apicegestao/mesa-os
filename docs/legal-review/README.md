## Como o sistema deve operar após a revisão

- O membro aceita o documento específico de Contexto Longitudinal em etapa separada dos Termos de Uso.
- O sistema guarda versão, hash, data/hora, identidade autenticada e recibo do aceite.
- O membro pode consultar os recibos e desligar futuras derivações automáticas.
- O contexto automático é limitado a registros canônicos da própria organização; chat bruto e dados sensíveis permanecem excluídos.
- Nenhuma versão deste pacote deve ser publicada sem preencher os campos `[PREENCHER]` e sem aprovação jurídica.

## Observação importante

Este material é um rascunho de produto para revisão jurídica; não substitui parecer, política aprovada ou orientação profissional.
