# Definition Pack — RT-2.26I Adaptador de Ciclo Ativo

**Status:** APPROVED FOR HOMOLOGATION

## Fonte e dado mínimo

Quando um ciclo é criado como ativo, o TutorIA pode registrar para o owner que o iniciou somente: título do ciclo, período e sequência metodológica. A fonte é o próprio registro canônico `cycles`.

## Guardrails

- exige Termos atuais aceitos e política organizacional ativa;
- usa `created_by` como sujeito, sem inferir dados de terceiros;
- uma referência de ciclo produz no máximo uma memória;
- não grava prioridade detalhada, Missões, ferramentas, conversas ou dados sensíveis;
- é visível ao membro e pode ser invalidada.
