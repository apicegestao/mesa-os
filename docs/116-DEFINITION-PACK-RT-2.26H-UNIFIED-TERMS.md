# Definition Pack — RT-2.26H Termo Único, Temporal e Reaceite

**Status:** APPROVED FOR HOMOLOGATION

## Decisão

O Mesa OS exibirá um único Termo de Uso no primeiro acesso. O texto incorpora, em seção própria, a autorização para contexto longitudinal automático do TutorIA. O recibo preserva identidade, versão, hash e momento do aceite.

## Atualizações

- Versões publicadas são imutáveis.
- Apenas uma versão por código pode estar publicada por vez.
- Uma atualização retira a versão anterior de publicação, publica uma nova versão com hash e torna o novo aceite obrigatório no próximo acesso.
- O histórico dos recibos anteriores nunca é substituído.
- A política de contexto só é elegível quando aponta para a versão aceita mais recente.

## Operação controlada

Nesta fase, a publicação de um novo texto acontece por migration revisada, com conteúdo e hash no mesmo artefato de implantação. Não há editor livre no app nem alteração silenciosa. Um futuro backoffice de publicação exige Definition Pack próprio, RBAC, MFA, aprovação em duas etapas e auditoria.

## Garantias

- aceitar os Termos não autoriza chat bruto, dados sensíveis, treinamento de modelo, dados entre organizações ou autonomia decisória;
- retirar a personalização continua disponível em Conta e segurança;
- membro sem aceite da versão atual não acessa as áreas autenticadas até fazer a escolha.
